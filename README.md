# OCR-Card-Reader
This is an anki addon where you can scan a flashcard in real life and it will create a flashcard on the anki app! This is very helpful if you have many in real life flashcards and you cannot afford to type it all out.

##WARNING: Files Required
You need every file and folder otherwise the addon will not work
